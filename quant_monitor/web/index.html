数据源

API
AShareHub 服务端行情接口

通过 HTTP 批量获取自选实时快照，通过日线接口补充历史走势；本地 WebSocket 只转发采集结果。当前接口不提供五档盘口或分钟 K 线，非交易时段返回上一交易日收盘快照。

服务端管理

当前接口约定

  • GET /api/v1/sectors/banks银行板块聚合缓存、排名与分析
  • GET /api/v1/market/treemap行业与个股矩形树图缓存（不调用上游）
  • GET /api/v1/instruments全市场证券目录（默认本地缓存，refresh=true 才刷新）
  • GET /api/v1/overview通用市场概览兼容接口
  • GET /api/v1/market/quotes缓存市场行情（refresh=true 才可能消耗额度）
  • GET /api/v1/watchlist自选批量行情快照
  • GET /api/v1/bars/{symbol}价格、均线和成交量
  • GET /api/v1/analysis/{symbol}趋势、动量与风险分析
  • GET /api/v1/fundamentals/factors/as-of点时点银行基本面因子（缓存只读）
  • GET /api/v1/alerts告警记录
  • GET /api/v1/signals策略信号
  • GET /api/v1/system/status服务健康状态
  • WS /ws/market本地采集结果增量推送

⌂仅本地运行行情和策略数据由本机服务处理；Windows 一键脚本使用当前用户 DPAPI 加密凭据，并只向服务进程注入 API Key。免费额度为每日 100 次，页面显示的是本机进程估算值，不代表供应商账户的权威账单。
